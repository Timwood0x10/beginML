# [3.ResidualConnection] 残差连接与层归一化 (Add & Norm)

## 🧩 一、Residual Connection 是什么？

**一句话解释**：
残差连接的核心是 **显式地让网络学习“残差函数”（Residual Function）**，即学习“变化量”而不是“全量”。

### 1.1 数学定义
$$ \boxed{H(x) = x + F(x)} $$

其中：
- $x$：**Identity Mapping (恒等映射)**，数据通过 Shortcut (捷径) 无损流过。
- $F(x)$：**Residual Mapping (残差映射)**，网络实际需要学习的“修补部分”。
- $H(x)$：最终输出的理想映射。

### 1.2 核心直觉
> 💡 **比喻**：
> 传统的网络像是在“重写”一篇文章。
> 残差网络像是在“批改”一篇文章：$x$ 是原文，$F(x)$ 是老师的红笔修改意见。
> 如果没什么好改的，$F(x) \to 0$，输出就是原文 $x$。这保证了**加深网络层数，效果至少不会变差**（恒等映射）。

## ⚙️ 二、LayerNorm (层归一化) 的数学原理

在 Residual 之后，通常紧接 LayerNorm。Transformer 为什么用 LN 而不用 BN？

### 2.1 计算公式
对于输入向量 $x \in \mathbb{R}^d$，LayerNorm 在**特征维度**上进行归一化：

1.  **求均值 (Mean)**: $\mu = \frac{1}{d} \sum_{i=1}^d x_i$
2.  **求方差 (Variance)**: $\sigma^2 = \frac{1}{d} \sum_{i=1}^d (x_i - \mu)^2$
3.  **归一化 + 仿射变换**:
    $$ \boxed{\text{LN}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \cdot \gamma + \beta} $$
    *   $\gamma, \beta$ 是可学习的参数（Gain & Bias），保证模型能恢复原本的表达能力。

### 2.2 现代变体：RMSNorm (Llama 标配)
现代大模型（如 Llama, PaLM）常用 **RMSNorm**。它去掉了均值 $\mu$，只缩放幅度：
$$ \text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d} \sum x_i^2 + \epsilon}} \cdot \gamma $$
*   **优势**：计算更少，效果相当。

## 🏗️ 三、Transformer 中的位置架构

Transformer 的每个 Block 包含两个核心子层，每个子层后都接一个 **Add & Norm**。

### 1. Encoder Block (2 个残差结构)
$$
\begin{aligned}
x_1 &= \text{Norm}(x + \text{SelfAttention}(x)) \\
x_2 &= \text{Norm}(x_1 + \text{FFN}(x_1))
\end{aligned}
$$

### 2. Decoder Block (3 个残差结构) ⚠️
Decoder 多了一个 Cross-Attention 层：
$$
\begin{aligned}
x_1 &= \text{Norm}(x + \text{MaskedSelfAttention}(x)) \\
x_2 &= \text{Norm}(x_1 + \text{CrossAttention}(x_1, \text{EncoderOut})) \\
x_3 &= \text{Norm}(x_2 + \text{FFN}(x_2))
\end{aligned}
$$

## ⚖️ 四、关键抉择：Post-LN vs Pre-LN

LayerNorm 放在“加法前”还是“加法后”，决定了深层网络的生死。

### 1. Post-LN (原始 Transformer, BERT)
$$ x_{t+1} = \text{Norm}(x_t + F(x_t)) $$
*   **结构**：先做残差相加，再做归一化。
*   **优点**：如果能训练好，最终性能可能略好（归一化后的输出直接进入下一层，利用率高）。
*   **缺点**：**梯度在反向传播时容易爆炸**。在深层网络中，必须配合极小学习率和复杂的 Warmup 才能收敛。

### 2. Pre-LN (GPT-2, Llama, 现代主流)
$$ x_{t+1} = x_t + F(\text{Norm}(x_t)) $$
*   **结构**：先归一化输入，再进子层，最后残差相加。
*   **优点**：**训练极度稳定**。主干路径（Highway）始终是纯净的 $x + \dots + x$，梯度流极其通畅。
*   **缺点**：在极深层可能出现“表示坍缩”问题（但对现在的 LLM 来说不是瓶颈）。

> **🏆 结论**：现代大模型（LLM）几乎全部采用 **Pre-LN** 架构。

## 📈 五、为什么有效？(数学推导)

### 1. 解决梯度消失 (Gradient Vanishing)
考虑一个简化网络 $x_{L} = x_0 + \sum_{i=1}^L F_i(x_{i-1})$。
损失函数 $\mathcal{L}$ 对输入 $x_0$ 的梯度为：

$$
\frac{\partial \mathcal{L}}{\partial x_0} = \frac{\partial \mathcal{L}}{\partial x_L} \cdot \left( \boxed{1} + \frac{\partial}{\partial x_0} \sum_{i=1}^L F_i \right)
$$

*   **没有残差时**：梯度是连乘 $\prod \frac{\partial F}{\partial x}$。如果每层导数小于 1，乘几十次就变成了 0（梯度消失）。
*   **有残差时**：梯度包含了一个恒定的 **$1$**。
    *   这就像一条**“梯度高速公路” (Gradient Highway)**。
    *   无论网络多深，梯度信号总能通过这个 $1$ 无损地传回到底层。

### 2. 集成假说 (Ensemble Hypothesis)
残差网络可以被视为许多不同深度的浅层网络的**指数级集成**。
*   数据可以选择走 Shortcut（跳过当前层），也可以选择走 $F(x)$（经过当前层）。
*   一个 $L$ 层的 ResNet，实际上包含了 $2^L$ 条可能的路径组合。

## 🔍 六、LN vs BN (为什么不用 BatchNorm?)

| 特性 | LayerNorm (LN) | BatchNorm (BN) |
| :--- | :--- | :--- |
| **归一化轴** | **横向切**：对单个样本的所有特征做归一化 | **纵向切**：对Batch中所有样本的同一特征做归一化 |
| **Batch 依赖** | **不依赖** (Batch=1 也能跑) | **强依赖** (Batch太小统计不准) |
| **适用数据** | **变长序列 (RNN/Transformer)** | 固定尺寸图像 (CNN) |
| **推理阶段** | 计算逻辑与训练一致 | 需使用训练期统计的 Running Mean/Var |

> **核心原因**：
> NLP 句子长度不一（Padding 很多）。
> 如果用 BN，Padding 的 0 会严重干扰均值和方差的统计。
> 而 LN 是对“每个词向量自己”做归一化，完全不受句子长度和 Batch Size 影响。

## 💻 七、PyTorch 实现 (Pre-LN 代码)

```python
import torch
import torch.nn as nn

class ResidualBlock(nn.Module):
    def __init__(self, d_model):
        super().__init__()
        self.norm = nn.LayerNorm(d_model)     # 1. 归一化层
        self.attn = nn.MultiheadAttention(d_model, num_heads=8)
        self.dropout = nn.Dropout(0.1)

    def forward(self, x):
        # x shape: [seq_len, batch, d_model]
        
        # === Pre-LN 结构 ===
        
        # 1. 先保存残差 (Identity)
        residual = x 
        
        # 2. 归一化 (Norm)
        x_norm = self.norm(x)
        
        # 3. 子层计算 (Attention)
        attn_out, _ = self.attn(x_norm, x_norm, x_norm)
        
        # 4. 残差连接 (Add)
        output = residual + self.dropout(attn_out)
        
        return output
```
