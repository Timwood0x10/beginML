# 机器学习数学基础笔记总结

本目录包含了机器学习核心数学概念的详细笔记，从基础数学到高级理论，涵盖了现代机器学习算法背后的数学原理。这是一套旨在构建 **AGI（通用人工智能）数学基石** 的完整知识体系。

## 📚 目录结构

### 🎯 基础数学理论

#### [0.1. 微积分：深度学习的优化引擎](0.1.Calculus_Optimization_Engine.md)
- **核心内容**：从泰勒展开到自动微分(AD)，揭示 PyTorch `.backward()` 背后的数学原理
- **关键概念**：
  - **敏感度分析**：导数作为变化率的物理意义
  - **泰勒级数与曲率**：SGD(一阶)与牛顿法(二阶)的几何本质
  - **计算图与 VJP**：雅可比-向量积与反向传播的工程实现
  - **自动微分**：从零手写 MicroGrad 引擎
- **应用**：理解梯度流、优化动力学与训练稳定性

#### [0.2. 矩阵论：数据的几何与变换](0.2.Matrix_Geometry_Data.md)
- **核心内容**：张量运算、流形几何、SVD 与大模型微调原理
- **关键概念**：
  - **秩与模型容量**：秩崩溃(Rank Collapse)与死神经元
  - **特征值谱**：梯度爆炸/消失的谱半径解释
  - **Cover 定理与升维**：Embedding 与核技巧的几何原理
  - **SVD 与 LoRA**：低秩适应(Low-Rank Adaptation)的数学推导
  - **Hessian 谱分析**：鞍点与极小值的判定
- **应用**：模型压缩、参数高效微调(PEFT)、高维数据分析

#### [0.3. 概率与信息论：不确定性的量化](0.3.Probability_Information.md)
- **核心内容**：从贝叶斯公式到高维几何，构建 AI 的概率世界观
- **关键概念**：
  - **熵与困惑度**：LLM 训练目标与性能指标的数学本质
  - **KL 散度**：分布对齐与 RLHF 中的约束项
  - **高维概率论**：测度集中现象与“球壳”几何
  - **维度诅咒**：为什么欧氏距离在高维失效，而余弦相似度有效？
- **应用**：大语言模型原理、RAG 向量检索、不确定性建模

1. **基础数学**：微积分 → 矩阵论 → 概率论基础
2. **核心概念**：损失函数 → 梯度优化 → 正则化

1. **深度理论**：VC维理论 → 信息几何 → 训练动力学
2. **现代架构**：注意力机制 → 图神经网络 → 扩散模型
3. **高级主题**：概率编程 → 因果推断 → 强化学习理论

### 专家路径 (AGI 数学)
1. **几何与度量**：最优传输 → 多模态几何 → 希尔伯特空间
2. **逻辑与博弈**：博弈论 → 因果推断
3. **信号与系统**：信号处理 → 状态空间模型
