## 📚 核心概念

### 1. 优化算法

#### SGD (随机梯度下降)
```
θ_{t+1} = θ_t - η · ∇f(θ_t)
```
- **优点**：简单直接
- **缺点**：在山谷中震荡，收敛慢
- **表现**：红色路径，可能曲折

#### SGD + Momentum (动量)
```
v_t = μ · v_{t-1} + ∇f(θ_t)
θ_{t+1} = θ_t - η · v_t
```
- **优点**：累积梯度，加速收敛，减少震荡
- **缺点**：可能过冲
- **表现**：蓝色路径，更平滑

#### Adam (自适应矩估计)
```
m_t = β₁·m_{t-1} + (1-β₁)·∇f(θ_t)
v_t = β₂·v_{t-1} + (1-β₂)·∇f(θ_t)²
θ_{t+1} = θ_t - η · m̂_t / (√v̂_t + ε)
```
- **优点**：自适应学习率，鲁棒
- **缺点**：计算量大
- **表现**：绿色路径，通常最快

### 2. 测试函数特点

#### Sphere Function (球函数)
```
f(x,y) = x² + y²
```
- **类型**：简单凸函数
- **最优点**：(0, 0)
- **特点**：各向同性，所有方向梯度相同
- **用途**：测试基本收敛能力

#### Rosenbrock Function (玫瑰布罗克函数)
```
f(x,y) = (1-x)² + 100(y-x²)²
```
- **类型**：非凸，狭长山谷
- **最优点**：(1, 1)
- **特点**：山谷内几乎平坦，难以收敛
- **用途**：测试优化器在困难地形的表现

#### Rastrigin Function (拉斯特里金函数)
```
f(x,y) = 20 + x² - 10cos(2πx) + y² - 10cos(2πy)
```
- **类型**：高度非凸，多局部最优
- **最优点**：(0, 0)
- **特点**：大量局部极小值，易陷入
- **用途**：测试全局搜索能力

#### Beale Function
```
f(x,y) = (1.5-x+xy)² + (2.25-x+xy²)² + (2.625-x+xy³)²
```
- **类型**：非凸
- **最优点**：(3, 0.5)
- **特点**：不对称，多个局部最优
- **用途**：测试收敛稳定性

### 3. 参数说明

#### 学习率 (Learning Rate, η)
- **作用**：控制每步移动的距离
- **太小**：收敛慢，需要很多步
- **太大**：可能震荡或发散
- **典型值**：0.001 ~ 0.1
- **观察**：看路径的步长和方向变化

#### 动量系数 (Momentum, μ)
- **作用**：累积历史梯度，平滑优化路径
- **范围**：[0, 1)
- **μ=0**：无动量，就是SGD
- **μ=0.9**：常用值，适度加速
- **μ→1**：强动量，可能过冲
- **观察**：看路径是否更平滑、更直接

## 💡 常见问题

### Q1: 为什么有些算法路径看不见？
**A:** 可能超出了显示范围（发散了）。点击图例隐藏发散的算法，或者调整学习率。

### Q2: 如何修改参数？
**A:** 当前版本参数是预设的。如果想自定义，需要：
1. 修改 `interactive_gradient_descent.py` 中的参数
2. 重新运行脚本生成新的HTML

### Q3: 为什么Adam这么快？
**A:** Adam结合了动量和自适应学习率，每个参数有独立的学习率，更适应不同方向的梯度。

### Q4: 哪个算法最好？
**A:** 
- **训练深度学习**：Adam/AdamW（默认选择）
- **大规模CV**：SGD+Momentum（更好泛化）
- **小数据集**：LBFGS（二阶方法）
- **强化学习**：Adam

### Q5: 为什么Rosenbrock这么难？
**A:** 因为山谷太窄，垂直于山谷的梯度很大，沿山谷的梯度很小，导致算法在两壁之间震荡，沿山谷前进缓慢。

## 📊 数学公式速查

### 梯度下降基础
```
∇f = [∂f/∂x, ∂f/∂y]  # 梯度（最陡上升方向）
θ_{t+1} = θ_t - η·∇f   # 沿负梯度方向更新
```

### 收敛条件
```
||θ_{t+1} - θ_t|| < ε  # 参数变化小于阈值
||∇f(θ_t)|| < ε        # 梯度接近零
```

### 学习率调度
```
η_t = η_0 / (1 + decay·t)     # 时间衰减
η_t = η_0 · 0.1^{t/step}      # 阶梯衰减
η_t = η_0 · cos(t/T·π/2)      # 余弦退火
```
