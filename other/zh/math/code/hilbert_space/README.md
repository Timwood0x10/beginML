## 🎯 可视化内容详解

### 📊 基础可视化 (2D)

### 1️⃣ 希尔伯特空间内积几何意义 (`1_hilbert_inner_product.html`)

**核心概念**：
- 内积的几何解释：⟨v₁, v₂⟩ = ||v₁|| · ||v₂|| · cos(θ)
- 向量投影与相似度度量
- 希尔伯特空间中的角度概念

**交互功能**：
- 动态调整向量角度
- 实时计算内积值
- 可视化投影关系

**数学公式**：
```
⟨v₁, v₂⟩ = ∫ v₁(x) · v₂(x) dx
```

### 2️⃣ 傅里叶变换作为酉算子 (`2_fourier_unitary.html`)

**核心概念**：
- Parseval恒等式：能量守恒
- 酉变换的性质：保持内积不变
- 连续与离散傅里叶变换的区别

**技术澄清**：
- 连续空间：L²(ℝᵈ) 无限维希尔伯特空间
- 离散空间：ℂᴺ 有限维希尔伯特空间
- DFT也是酉变换，但定义域不同

**关键公式**：
```
⟨f, g⟩ = ⟨ℱ{f}, ℱ{g}⟩  (Parseval恒等式)
```

### 3️⃣ 卷积定理动态演示 (`3_convolution_theorem.html`)

**核心概念**：
- 卷积定理：ℱ{f * g} = ℱ{f} · ℱ{g}
- 时域卷积与频域相乘的等价性
- FFT算法的计算优势

**⚠️ 工程实现澄清**：
- 数学上：时域卷积 = 频域相乘
- 实际CNN：时域直接实现，频域仅用于理论分析
- FFT卷积：仅用于大核或特定优化场景

**计算复杂度**：
- 直接卷积：O(n²)
- FFT卷积：O(n log n)
- 拐点：n ≈ 32 时FFT开始有优势

### 4️⃣ CNN滤波器频域特性 (`4_cnn_frequency_analysis.html`)

**观察现象**：
- 训练得到的CNN滤波器通常呈现低通特性
- 深层网络学习更精细的频率结构
- 不同类型滤波器的频域响应

**滤波器类型**：
- 低通滤波器：保留低频成分
- 高通滤波器：增强高频成分
- 边缘检测：检测信号变化
- 拉普拉斯算子：二阶微分

**工程意义**：
- 理解CNN学到的频率表示
- 指导滤波器设计
- 解释网络层次化学习过程

### 5️⃣ 图傅里叶变换与GNN (`5_graph_fourier.html`)

**核心概念**：
- 图拉普拉斯矩阵：L = D - A
- 特征分解：L = UΛUᵀ
- 图傅里叶变换：𝑥̂ = Uᵀx

**图频率的物理意义**：
- 低特征值：缓慢变化的图模式（相邻节点相似）
- 高特征值：快速变化的图模式（相邻节点差异大）
- 频率 = 信号在图上的变化率

**与CNN的区别**：
- CNN频率：基于空间几何频率
- 图频率：基于图结构特征
- 数学本质：都是希尔伯特空间中的正交基

### 6️⃣ Transformer位置编码分析 (`6_transformer_positional.html`)

**位置编码公式**：
```
PE_(pos,2i) = sin(pos/10000^(2i/d))
PE_(pos,2i+1) = cos(pos/10000^(2i/d))
```

**⚠️ 正交性澄清**：
- Transformer使用非整数频率
- 在有限序列上呈现"近似正交"
- 不是严格的傅里叶正交基，但提供多尺度频率覆盖

**分析维度**：
- 编码矩阵可视化
- 频谱分析
- 正交性定量分析
