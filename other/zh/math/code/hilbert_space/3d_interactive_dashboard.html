1️⃣ 希尔伯特空间内积几何意义

内积定义： ⟨v₁, v₂⟩ = ||v₁|| · ||v₂|| · cos(θ)
💡 核心洞察： 从2D到3D，内积的几何意义保持不变：一个向量在另一个向量上的投影。 在高维空间中，这个概念推广到任意维度。

高维内积：
设 x, y ∈ ℝⁿ，则内积为：
⟨x, y⟩ = Σᵢ₌₁ⁿ xᵢ · yᵢ

几何意义：
• 夹角：cos(θ) = ⟨x,y⟩/(||x||·||y||)

• 正交：⟨x,y⟩ = 0 ⟺ x ⊥ y
