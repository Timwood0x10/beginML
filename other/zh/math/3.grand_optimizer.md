## pythorch 中的梯度优化算法 

### 一、优化器到底在做什么（所有优化器的共同底层）

- 目标：让参数 $\theta$ 往降低损失 $L(\theta)$ 的方向走
- 梯度 $g = \nabla \theta L(\theta)$ 告诉我们`往哪走`
- 最基础更新：$\theta \leftarrow \theta - \eta \cdot g$
  - $\eta$ = 学习率（每步走多大）

多数优化器 = 在这个模板上加几个`插件`：
- 动量（Momentum）：记住`历史方向`（像惯性/滚雪球）
- 自适应步长（Adaptive）：每个参数有自己的步长（容易学的走小步，难学的走大步）
- 偏差校正（Bias correction）：刚起步时统计不准，先校正一下
- 权重衰减（Weight Decay）：等价`L2正则`，防止过拟合

### 二、PyTorch 里都有哪些优化器（按思路分组）

A. 基础 + 动量系列

1) SGD（随机梯度下降）
- 更新：$\theta \leftarrow \theta - \eta \cdot g$
- 直觉：只看当前坡度往下走
- 何时用：小模型、规则数据，或你配合好的学习率调度（常见于从头训练大规模视觉模型）

2) SGD + Momentum（动量）
- 公式：
  - $v \leftarrow \mu \cdot v + g$
  - $\theta \leftarrow \theta - \eta \cdot v$
- 直觉：像滚雪球，方向长期一致就越滚越快，爬小坑不容易卡住
- 何时用：比纯SGD更稳更快，是`经典可靠的基线`

3) Nesterov（NAG，带`预见`的动量）
- 公式（直观写法）：
  - 先看一步：$ḡ = \nabla L(\theta - \eta \cdot \mu \cdot v)$
  - $v \leftarrow \mu \cdot v + ḡ$；$\theta \leftarrow \theta - \eta \cdot v$
- 直觉：先朝惯性方向探一步再决定力度，转弯更灵活
- 何时用：和Momentum类似，偶尔更快

B. 自适应步长系列（每个参数自己的步长）

4) Adagrad
- 公式：
  - $G \leftarrow G + g^2$（逐元素累加）
  - $\theta \leftarrow \theta - \eta \cdot g / \sqrt(G + \epsilon)$
- 直觉：梯度老是大的参数→步长自动变小；稀疏特征→能学得更快
- 缺点：G 会越积越大，步长不断变小
- 何时用：稀疏特征（如NLP早期场景）

5) RMSprop
- 公式：
  - $E[g^2] \leftarrow \rho \cdot E[g^2] + (1-\rho) \cdot g^2$（滑动平均）
  - $\theta \leftarrow \theta - \eta \cdot g / \sqrt(E[g^2] + \epsilon)$
- 直觉：像`自适应减震`，看`最近一段时间`的梯度强弱
- 何时用：RNN/非平稳目标；现在多被 Adam 取代

6) Adadelta
- 思想：在 RMSprop 基础上，把学习率也自适应掉（用历史更新量来定步长）
- 直觉：完全免调学习率的小改良
- 何时用：不想手调 lr 的小任务

C. Adam 家族（动量 + 自适应 的合体，最常用）

7) Adam（默认首选之一）
- 公式（记住这三行就够）：
  - $m \leftarrow \beta_1 \cdot m + (1-\beta_1) \cdot g$（梯度平均，像动量）
  - $v \leftarrow \beta_2 \cdot v + (1-\beta_2) \cdot g^2$（梯度平方平均，像RMSprop）
  - $\theta \leftarrow \theta - \eta \cdot \hat{m} / (\sqrt{\hat{v}} + \epsilon)$（m̂、v̂ 是偏差校正）
- 直觉：方向有记忆（不抖），步长自适应（不乱冲）
- 何时用：几乎所有深度学习任务的好起点

8) AdamW（强烈推荐）
- 差别：把`权重衰减`从 Adam 中`解耦`出来，正则化更正确
- 直觉：Adam 的更可靠版本，现代大模型（BERT/GPT/ViT）标配
- 何时用：默认用它；NLP微调常用 lr≈2e−5~5e−5；CV/MLP常用 lr≈1e−3

9) RAdam（Rectified Adam）
- 思想：Adam 的自适应在初期统计不稳，先`暖一暖`再放开
- 直觉：一上来别猛跑，先稳住
- 何时用：小 batch 或训练初期容易不稳的任务

10) NAdam（Nesterov Adam）
- 思想：Adam + Nesterov 动量
- 直觉：Adam 再加点`预见性`的加速
- 何时用：效果和 Adam 接近，偶尔更快

11) Adamax
- 思想：把 v 用`无穷范数`近似（对极端梯度更稳）
- 何时用：很少必需，作为 Adam 的小变种

12) SparseAdam
- 思想：只更新`出现过`的行（用于稀疏梯度）
- 何时用：巨大的 embedding/词表

D. 其他类

13) RMSprop（上面已有）/ Rprop（Resilient backprop）
- Rprop 公式（核心思想）：
  - 只看梯度符号，不看大小；同号→步长乘1.2，异号→乘0.5
  - $\theta \leftarrow \theta - sign(g) \cdot \Delta$（Δ为每参数自己的步长）
- 直觉：不吃梯度大小的亏，参数自己学步长
- 何时用：小/浅网络、非深度任务

14) ASGD（Averaged SGD）
- 思想：对参数做滑动平均，收敛更平稳
- 何时用：凸问题/线性模型，更偏传统

15) LBFGS（拟牛顿，二阶近似）
- 直觉：不只看坡度，还估个`弯曲度`，一步到位更快
- 限制：要较大 batch 或全量梯度，内存占用高
- 何时用：小模型/小数据想快速高精收敛（如风格迁移、线性/浅层网络）

### 三、选型口诀（不想纠结就照这个来）

- 不知道用啥：AdamW（99% 情况都够用）
- 从零训练大规模图像分类：SGD + Momentum + 学习率调度（cos/step）常更强
- 词表/Embedding 很大且梯度稀疏：SparseAdam 或 Adagrad
- 小 batch 或训练初期不稳：RAdam（或 AdamW + warmup）
- 小模型/小数据想快收敛：LBFGS
- RNN/老项目：RMSprop 也可一试

### 四、PyTorch 怎么用（换优化器=改一行）

```python
import torch.optim as optim

# 常用
optim.Adam(model.parameters(), lr=1e-3)
optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-2)
optim.SGD(model.parameters(), lr=0.1, momentum=0.9, nesterov=True)

# 自适应类
optim.Adagrad(model.parameters(), lr=1e-2)
optim.RMSprop(model.parameters(), lr=1e-3, alpha=0.99)
optim.Adadelta(model.parameters())  # 通常不设 lr

# Adam 家族
optim.RAdam(model.parameters(), lr=1e-3)
optim.NAdam(model.parameters(), lr=1e-3)
optim.Adamax(model.parameters(), lr=2e-3)
optim.SparseAdam(model.parameters(), lr=1e-3)  # 只给稀疏参数用

# 其他
optim.Rprop(model.parameters(), lr=1e-2)
optim.ASGD(model.parameters(), lr=1e-2)
optim.LBFGS(model.parameters(), lr=1.0)  # 需要自定义 closure
```

五、把`数学`再说人话（四个核心插件的直觉）

- 动量 v：像惯性。公式 $v \leftarrow \mu v + g$；$\theta \leftarrow \theta - \eta v$
  - 好处：直道加速，拐弯更稳，不轻易被小坑困住
- 自适应分母 √(统计量)：像自动档。分母大→步子小；分母小→步子大
  - Adagrad：用`历史平方和`当分母（会越跑越慢）
  - RMSprop/Adam：用`最近的滑动平均`当分母（更灵活）
- 偏差校正 $\hat{m}$、$\hat{v}$：刚起步数据少，先把`偏差`除掉
- 权重衰减（weight_decay）：每步把权重往0拉一点（防过拟合）
  - AdamW 把它`单独处理`，不影响自适应分母（这点比 Adam 正确）

### 六、常用超参小抄（起步别纠结）

- AdamW：lr=1e−3（MLP/CNN），β=(0.9, 0.999)，weight_decay=1e−2；NLP微调 lr=2e−5~5e−5
- SGD+Momentum：lr=0.1（配合余弦/阶梯衰减），momentum=0.9，weight_decay=1e−4
- RMSprop：lr=1e−3，alpha=0.99
- Adagrad：lr=1e−2
- RAdam/NAdam：lr=1e−3

小技巧：
- 训练不稳/梯度大：梯度裁剪（clip_grad_norm_）
- 先大后小：用学习率调度（cosine/step/warmup）

### 七、学习率调度器（Scheduler）：给优化器装个变速箱
优化器决定方向，学习率（LR）决定步幅。全程用同一个 LR 往往不是最优解：
- 前期：离目标远，步子要大（或者先热身）。
- 后期：离目标近，步子要小，不然会在坑底反复横跳进不去。
PyTorch 的 torch.optim.lr_scheduler 提供了这些变速策略：
1. StepLR / MultiStepLR（阶梯式衰减）
- 直觉：每过固定的 Epoch，就把学习率打个折。像下楼梯。
  ```python
  # 每 30 epoch，lr = lr * 0.1
  scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=30, gamma=0.1)
  ```

- 场景：经典 CNN 训练（如 ResNet 刷榜 ImageNet）。

2. CosineAnnealingLR / CosineAnnealingWarmRestarts（余弦退火）
- 直觉：用余弦函数调和学习率，前期大，后期小。像潮汐。
  ```python
  # 余弦退火
  scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=10)
  ```
- 场景：目前最流行、通用的选择，特别是从头训练时。


3. ReduceLROnPlateau（监控式衰减）
- 直觉：盯着 Loss 或 Accuracy 看。如果连续 N 次（patience）没起色，就强制减速（"既然卡住了，那就走细一点试试"）。
  ```python
  # 监控指标不再下降时，lr = lr * 0.1
  scheduler = optim.lr_scheduler.ReduceLROnPlateau(optimizer, mode='min', patience=10, factor=0.1)

  # 注意：这个 scheduler 需要在 step 时传参
  # scheduler.step(val_loss)
  ```
- 场景：当你不知道该怎么设 decay 时，让模型自己看着办。

4. LinearLR / Warmup（热身）
- 直觉：刚开始训练时，参数是随机的，梯度可能极其不稳定。如果 LR 上来就很大，容易把模型`带偏`。所以先用极小的 LR 跑几步（Warmup），等模型“热”了再加速。
- 实现：通常配合 SequentialLR 使用，或者用 HuggingFace 的 get_linear_schedule_with_warmup。

八、进阶优化技巧（防炸、省显存、提分）
1. 梯度裁剪（Gradient Clipping）
- 问题：有时候（特别是 RNN 或深层网络），梯度会突然变得超级大（梯度爆炸），参数一下飞出银河系，Loss 变成 NaN。
- 对策：不管梯度多大，强制把它“砍”到一个固定范数内。
- 代码（放在 backward() 之后，step() 之前）：
  ```python
  loss.backward()
  # 将梯度范数裁剪到 max_norm=1.0
  torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
  optimizer.step()
  ```

2. 梯度累积（Gradient Accumulation）
- 问题：显存太小，Batch Size 只能开到 8，但你想用 64 的 Batch Size 效果？
- 对策：跑 8 次 forward/backward，把梯度攒起来，攒够 64 份再更新一次参数。
  ```python
  accumulation_steps = 8

  for i, (inputs, labels) in enumerate(dataloader):
      outputs = model(inputs)
      loss = criterion(outputs, labels)
      
      # 注意：loss 要除以累积步数，因为 backward 会自动累加梯度
      loss = loss / accumulation_steps 
      loss.backward()
      
      if (i + 1) % accumulation_steps == 0:
          optimizer.step()    # 更新参数
          optimizer.zero_grad() # 清空梯度
  ```

3.LBFGS 的特殊用法（Closure）
- 背景：LBFGS 需要多次计算函数值来评估曲率，所以用法和 SGD/Adam 不一样。
```python
optimizer = optim.LBFGS(model.parameters(), lr=1)

def closure():
    optimizer.zero_grad()
    output = model(input)
    loss = criterion(output, target)
    loss.backward()
    return loss

# step 的时候要把 closure 函数传进去
optimizer.step(closure)
```

4.SWA (Stochastic Weight Averaging)
- 直觉：在训练末期，模型会在最优解附近震荡。SGD 停在的地方可能不是正中心。SWA 把末期多个时间点的权重取平均值，通常能找到更平坦（泛化更好）的谷底。
- 用法：torch.optim.swa_utils。
- 场景：比赛刷分利器，提升泛化能力。

九、常见`问题`诊断与急救
优化器不是万能的，遇到 Loss 异常先别慌：

1.Loss 为 NaN（Not a Number）
  - 原因：梯度爆炸、学习率太大、除以零（输入数据有 0 或 NaN）。
  - 急救：调小 LR、加梯度裁剪、检查输入数据、检查分母有没有加 epsilon。

2.Loss 不降（Stuck）
  - 原因：LR 太小（像是蚂蚁搬家）、初始化太差、代码写错了（比如没写 optimizer.zero_grad() 导致梯度一直累加）。
  - 急救：调大 LR 10 倍试试、检查代码逻辑。

3. Loss 震荡剧烈（Oscillation）
  - 原因：Batch Size 太小、LR 太大。
  - 急救：调小 LR、增大 Batch Size。

4.训练集 Loss 降了，测试集 Loss 升了
  - 原因：过拟合（Overfitting）。
  - 急救：AdamW 加大 weight_decay、加 Dropout、加数据增强、早停（Early Stopping）。

---

十、终极总结（One-Liner）
- 无脑首选：AdamW(lr=1e-3, weight_decay=1e-2)
- CV 刷榜：SGD(momentum=0.9) + CosineAnnealingLR
- 显存不够：用梯度累积。
- 训练炸了：加梯度裁剪。
- 微调大模型：LR 开极小（1e-5 级别）。
