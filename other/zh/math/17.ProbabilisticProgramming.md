## 贝叶斯深度学习与概率编程：权重的不确定性量化

⚠️ 宏观视角：神经网络的`第三次数学飞跃`
回顾我们构建的 AI 数学大厦，可以看到三次明显的认知飞跃：

- 第一次飞跃（函数拟合）：认为神经网络是一个复杂的函数 $y=f(x;w)$
。目标是找到一组最优的权重 $w^*$（点估计），使得误差最小。这是 SGD 和 反向传播 的时代。

- 第二次飞跃（生成模型）：认为数据 $x$ 服从某种分布 $p(x)$
。目标是学习这个分布并采样。这是 GAN、VAE 和 扩散模型 的时代。

- 第三次飞跃（贝叶斯深度学习）：认为权重 $w$ 本身也是随机变量，服从某种分布 $p(w|D)$
    - 核心思想：我们永远无法找到`唯一正确`的权重。

    - 目标：不再是寻找山峰的顶点（MLE），而是描绘整座山的形状（后验推断）。

这篇笔记将探讨在所有深度学习框架（TensorFlow, PyTorch, JAX, Julia）背后通用的概率编程数学原理。

---
## 一、频率派 vs 贝叶斯派：世界观的冲突

在深度学习中，我们通常面临两种参数估计的哲学：

### 1.1 频率派 (Frequentist) —— 极大似然估计 (MLE)

这是我们前 16 篇笔记默认的视角。
假设：存在一组客观真实的、固定的权重 $w^*$
。方法：通过数据 $D$，找到最像 $w^*$ 的那个点。

$$
w_{MLE}=argmax_{w}P(D|w)
$$

- 局限：过度自信 (Overconfidence)。即使面对从未见过的数据，模型也会给出一个确定的预测值，因为它不知道自己`不知道`。

### 1.2 贝叶斯派 (Bayesian) —— 后验推断

这是概率编程的视角。

- 假设：权重 $w$ 是不确定的，它是一个概率分布。我们对它有一个先验认知 
$P(w)$（比如认为权重服从高斯分布）。
方法：观测到数据$D$后，更新我们对 $w$ 的信念，得到后验分布 $P(w|D)$。

$$
p(w|D) = \frac{p(D|w)p(w)}{p(D)}
$$

- 局限：过度不确定性 (Underconfidence)。计算不可行 (Intractable)。且结果对`先验分布`的选择敏感。

## 二、核心数学困境：无法计算的证据 (The Intractable Evidence)

贝叶斯公式看起来简单，但在神经网络中，它包含一个数学黑洞:分母$p(D)$

$$
p(D) = \int p(D|w)p(w)dw
$$

- 物理意义：这是边缘似然 (Marginal Likelihood)，也叫模型证据 (Model Evidence)。它代表了模型生成当前数据的总概率。

- 计算灾难：
    - 对于简单的线性回归，这个积分有解析解。
    - 对于深度神经网络，权重$w$ 的维度可能有 10 亿维。在高维空间对非凸函数进行积分，是目前数学上无法精确求解的 (Intractable)。

整个概率编程和贝叶斯深度学习的历史，就是一部`如何绕过这个积分`的斗争史。

## 三、 两个流派：蒙特卡洛 MCMC vs 变分推断 VI

为了绕过那个算不出来的积分，数学家和计算机科学家提出了两种截然不同的路径。这两种路径在所有框架（TF, PyTorch, JAX）中都是通用的。

### 3.1 流派一：变分推断 (Variational Inference, VI)

思想：把`积分问题`转化为`优化问题`。

既然算不出真实的后验 $P(w|D)$，那我们就找一个简单的已知分布族 $q_\theta(w)$（比如高斯分布），然后调整 $\theta$，让 $q_\theta(w)$ 尽可能像 $P(w|D)$。

数学工具：KL 散度 (KL Divergence):

目标最小化：$KL(q_\theta(w) || P(w|D))$  经过推导（详见下文），这等价于最大化 证据下界 (ELBO)：
$$
L(\theta) = \mathbb{E}_{w \sim q_\theta}\left[\log P(D \mid w)\right] - \text{KL}\left(q_{\theta}(w) \mid\mid P(w)\right)
$$

直观解释：
- 第一项：重构误差。要求采样出来的权重能很好地拟合数据。

- 第二项：正则项。要求近似分布 $q$ 不能偏离先验 $p$ 太远。

- 优点：快！可以用 SGD 进行反向传播训练。是工业界应用的主流。

- 缺点：因为假设了 $q$ 是简单的（通常是高斯），所以往往会低估方差。

### 3.2 流派二：马尔可夫链蒙特卡洛 (MCMC)

思想：把`计算问题`转化为`采样问题`。
既然算不出分布的解析式，我就设计一个物理过程（马尔可夫链），让粒子在这个空间里游走。当时间趋于无穷时，粒子出现的位置就服从后验分布 $p(w|D)$。

数学工具：哈密顿动力学 (Hamiltonian Dynamics)

为了在高维空间高效游走，最先进的算法（如 HMC 和 NUTS）引入了物理学中的`动量`概念。

$$
H(w,p) = U(w) + K(p)
$$

把负对数概率看作`势能` $U(w)$，引入辅助变量`动量` $p$。粒子不是盲目随机跳跃，而是沿着等势线滑行。

- 优点：精确！理论上可以收敛到真实后验，是`金标准`。
- 缺点：慢！计算成本极高，通常难以用于大型神经网络。

## 四、连接数学与工程的桥梁：重参数化技巧 (Reparameterization Trick)

这是深度学习框架（无论是 TF 还是 PyTorch）能够训练概率模型的关键技术。

问题：如果在网络中间有一个采样操作 $z \sim N(\mu, \sigma)$，采样是随机的，导致计算图断裂，梯度无法反向传播。

解决方案：将随机性剥离到外部。

我们不直接采样 $z$，而是采样一个标准的噪声 $\epsilon \sim N(0, 1)$，然后令：
$$
z = \mu + \sigma \odot \epsilon
$$

数学意义：
现在，$z$变成了一个关于 $\mu$ 和 $\sigma$ 的确定性函数（虽然带了噪声参数）。
$$
\frac{\partial z}{\partial \mu} = 1, \frac{\partial z}{\partial \sigma} = \epsilon
$$

梯度可以流动了！ 这使得变分推断 (VI) 可以像普通神经网络一样，利用 GPU 加速和 Adam 优化器进行训练。

## 五、不确定性的分类：我们到底在不确定什么？

在宏观视角下，概率编程帮助我们区分了两种本质不同的不确定性：
### 5.1 任意不确定性 (Aleatoric Uncertainty)


- 来源：数据本身固有的噪声（如传感器的误差、硬币的随机性）。

- 特点：无法通过更多数据消除。

- 建模：在 Loss 函数中引入 $\sigma$ 项（如第 9 篇笔记所述）。

### 5.2 认知不确定性 (Epistemic Uncertainty)

- 来源：模型`没见过`这种数据，或者模型结构不够好。这是**知识的盲区**。

- 特点：可以通过增加数据来消除。

- 建模：必须使用贝叶斯神经网络 (BNN)，让权重变成分布。

宏观结论：传统神经网络只能捕捉第一种；只有贝叶斯深度学习能同时捕捉第二种。这对于自动驾驶（遇到未见过的路况）和医疗诊断（遇到罕见病）至关重要。

## 六、宏观生态与工程落地：代码中的范式转移

数学原理在工程中是如何落地的？不同的深度学习框架提供了不同的方言，但它们都在做同一件事：**将神经网络层从“确定性计算”改造为“概率性采样”。**

我们通过对比最主流的三大生态，来看看这“一行代码的质变”到底发生了什么。

### 6.0 基准：传统确定性网络 (Standard PyTorch)
在传统的深度学习中，权重是固定的参数 (Parameter)。

```python
# y = x @ w + b
# 每次前向传播，w 和 b 都是固定的数值
layer = nn.Linear(in_features=10, out_features=1)
```


### 6.1 TensorFlow 生态 (TFP - TensorFlow Probability)

定位：工业级、Google 出品、深度集成 Keras。

特点：API 高度封装，支持 TPU 加速，适合超大规模模型。
代码质变：

TFP 提供了`概率层` (Probabilistic Layers)，它自动处理了重参数化技巧和 KL 散度的计算。

```python
import tensorflow_probability as tfp
tfd = tfp.distributions

# 定义层：权重不再是变量，而是服从正态分布的随机变量
# Flipout 是一种高效的蒙特卡洛估算技巧
layer = tfp.layers.DenseFlipout(
    units=1,
    kernel_prior_fn=tfp.layers.default_multivariate_normal_fn, # 先验 P(w)
    kernel_posterior_fn=tfp.layers.default_mean_field_normal_fn() # 变分后验 q(w)
)
# 这一行代码背后，TFP 自动在 Loss 中加入了 KL 散度项 (ELBO 的一部分)
```

### 6.2 PyTorch 生态 (Pyro / GPyTorch)

定位：学术级、Uber 出品、深度集成 PyTorch。

特点：动态图特性使得编写复杂的概率模型（如带有循环和递归的模型）非常直观。学术界使用极多。

代码质变：
Pyro 不封装层，而是通过 pyro.sample 原语，强迫开发者显式地思考每一个参数的分布。

```python
import pyro
import pyro.distributions as dist

# 必须显式定义权重的分布
# 1. 定义先验 (Prior)
w_dist = dist.Normal(0, 1)
b_dist = dist.Normal(0, 1)

# 2. 采样 (Sample) - 这一步发生了重参数化
w = pyro.sample("w", w_dist)
b = pyro.sample("b", b_dist)

# 3. 计算 (Compute)
y = x @ w + b
```


### 6.3 JAX 生态 (NumPyro / Distrax / Optax)

特点：利用 JAX 的 XLA 编译和自动向量化 (vmap)。

现状：NumPyro 的 MCMC 采样速度目前是业界标杆（比 Pyro 和 TFP 都快），因为 HMC/NUTS 非常适合 JAX 的计算模式。

代码质变：
代码风格是函数式的（Functional），无状态的。

```python
import numpyro
import numpyro.distributions as dist
import jax.numpy as jnp

def model(x, y=None):
    # 语法与 Pyro 类似，但底层运行在 XLA 编译器上
    w = numpyro.sample("w", dist.Normal(jnp.zeros((10, 1)), jnp.ones((10, 1))))
    b = numpyro.sample("b", dist.Normal(0., 1.))
    
    # JAX 的矩阵乘法
    mu = jnp.dot(x, w) + b
    
    # 观测数据
    numpyro.sample("obs", dist.Normal(mu, 1.0), obs=y)
```


### 6.4 Julia 生态 (Turing.jl)
特点：语法最接近数学公式，科学计算领域的首选。

### 6.5 结论,殊途同归

尽管 TFP 封装了 Layer，Pyro 暴露了 Sample，NumPyro 优化了编译，但它们背后的数学基石是永恒的：

1. ELBO：都在试图最大化证据下界。

2. Reparameterization：都在把随机性剥离到 $\epsilon$，让梯度能流动。

3. KL Divergence：都在用 KL 散度约束后验不偏离先验。

工具会变，但**将权重视为分布**这一贝叶斯思想，是所有这些框架的共同灵魂。

## 七、终极总结

第 17 篇笔记标志着我们对 AI 理解的升华：

从 [0-14] 确定性世界：$y=f(x)$。追求预测的准确度。

到 [15] 动态过程：
$$
dx=f(x)dt+g(t)dW
$$ 
引入物理时间的演化。

再到 [17] 概率世界：
$$
w\sim P(w|D)
$$
。追求对自身无知的认知。

贝叶斯深度学习不仅仅是一种技术，更是一种世界观：承认模型永远无法完美，并诚实地量化这种不完美。
