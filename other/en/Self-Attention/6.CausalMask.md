# Lower-Triangular Mask (Causal Mask) Explained

### Core Concept: The Decoder's `Time Machine Lock`

In the **Masked Self-Attention** of the Transformer Decoder, the **lower-triangular Mask** (also called Causal Mask or Future Mask) is the key mechanism that ensures the model can do **autoregressive generation** (Autoregressive).

It acts like a **`time lock`**: when predicting the $t$-th word, the model is forced to only see words $1$ through $t$, and must never `peek` at word $t+1$ or later.

---

### Part 1: What Is a Lower-Triangular Mask?

#### 1. Definition

It is an $L \times L$ matrix ($L$ is the sequence length), whose values form a clear **lower-triangular structure**:

* **Lower triangle (including the diagonal)**: value $0$ (or `True`). Represents **`the past and the present`** — attention is allowed.
* **Upper triangle**: value $-\infty$ (or `False`). Represents **`the future`** — attention is forbidden.

#### 2. Intuitive Matrix Example

Suppose the sequence length is $L=4$. The mask matrix $\mathbf{M}$ is:

$$
\mathbf{M} = \begin{bmatrix} 
\color{green}{0} & \color{red}{-\infty} & \color{red}{-\infty} & \color{red}{-\infty} \\
\color{green}{0} & \color{green}{0} & \color{red}{-\infty} & \color{red}{-\infty} \\
\color{green}{0} & \color{green}{0} & \color{green}{0} & \color{red}{-\infty} \\
\color{green}{0} & \color{green}{0} & \color{green}{0} & \color{green}{0} 
\end{bmatrix}
$$

* **Row (Query)**: the current time step $t$.
* **Column (Key)**: a historical time step $i$.
* **Reading it**: row 2 (index 1) can only see columns 0 and 1; columns 2 and 3 are blocked by $-\infty$.

---

### Part 2: The Math: How Does It Work?

The Mask is **added (Add)** directly onto the scores of Scaled Dot-Product Attention.

#### 1. Formula

$$
\text{Attention}(Q, K, V) = \text{softmax}\left( \frac{Q K^T}{\sqrt{d_k}} + \boxed{\mathbf{M}} \right) V
$$

#### 2. Why Add $-\infty$?

* A property of the Softmax function: $e^{-\infty} \approx 0$.
* When $\text{Score} + (-\infty)$, the result is still $-\infty$.
* After Softmax normalization, the probability weight at that position becomes **strictly 0**.
  * $\text{softmax}([2.5, -\infty, -\infty]) \rightarrow [1.0, 0.0, 0.0]$
* This means: **the model's attention weight on future information is forced to zero, completely cutting off the information flow.**

### Part 3: Code Implementation (PyTorch)

In PyTorch, we usually use `torch.triu` (upper triangular) to create the upper-triangular matrix, then invert or fill it.

```python
import torch

def create_causal_mask(seq_len):
    # 1. Create an all-ones matrix
    # 2. torch.triu(..., diagonal=1) keeps the upper triangle (excluding the diagonal), the rest is 0
    # 3. Replace the 1s in the upper triangle with -inf, keep the rest as 0
  
    mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1)
  
    # Turn 1 (future) into -inf
    # Keep 0 (past) as 0
    mask = mask.masked_fill(mask == 1, float('-inf'))
  
    return mask

# Test
L = 4
mask = create_causal_mask(L)
print(mask)

# Output:
# tensor([[0., -inf, -inf, -inf],
#         [0., 0., -inf, -inf],
#         [0., 0., 0., -inf],
#         [0., 0., 0., 0.]])
```

### Part 4: Going Further: Causal Mask vs Padding Mask

In real engineering (e.g., HuggingFace Transformers), the mask received by the Decoder is usually a combination of the **Causal Mask** and the **Padding Mask**.

1. **Causal Mask**: the lower-triangular mask here, responsible for blocking `the future`.
2. **Padding Mask**: responsible for blocking `<pad>` placeholders.

**Final Mask** = $\max(\text{CausalMask}, \text{PaddingMask})$
*(Note: since both are negative infinity, the max operation correctly merges the two masked regions)*

### Part 5: Common Misconceptions (FAQ)

**Q1: Does the Decoder's Cross-Attention need this Mask?**

> **No!**
> Cross-Attention is the Decoder consulting the Encoder's output. The Encoder's output is already-computed, complete source information (Keys/Values), and the Decoder is entitled to look at **all positions** of the source (e.g., in translation, the first word may correspond to the last word of the source). So Cross-Attention does not use a Causal Mask.

**Q2: Why add the Mask during training too? Doesn't training already have the complete answer?**

> This is exactly the essence of **Teacher Forcing**!
> Even though we have the complete answer, we want the model to compute the loss **in parallel**.
> By adding the Mask, we can make position 1 predict position 2, position 2 predict position 3... all in a single matrix operation — like parallel universes, where every position believes it has only seen the past. This way we don't need a `for` loop that generates one token at a time like at inference time, dramatically improving training efficiency.

**Q3: Why not just delete the Keys/Values of future positions?**

> For **batch matrix computation (Batch Processing)**.
> If we deleted them, every position would see a different-length vector (position 1 has length 1, position 100 has length 100), producing a ragged tensor, which is extremely hard for GPUs to parallelize. Keeping the matrix shape regular (always $L \times L$) with a Mask is the computation pattern GPUs love most.

---

### Part 6: One-Sentence Summary

The lower-triangular Mask is an ingenious mechanism the Transformer invented to adapt to **GPU parallel computation**: while keeping the matrix shape intact, it logically **`blocks the future`** through math (adding $-\infty$), enabling efficient autoregressive training.
