# Transformer Decoder Explained

### Decoder Overview

The Decoder's job is to generate tokens one by one **auto-regressively**. It's like a writer who holds the `outline` (Context) given by the Encoder in one hand and writes the `novel` (Generated Sequence) with the other — every time it writes a word, it looks back at what it has already written.

### ⚙️ 1. The Full Structure of a Single Decoder Layer: Modern SOTA (Pre-LN)

Modern LLMs (such as LLaMA, GPT-4) usually adopt a **Decoder-Only** architecture (removing Cross-Attention), while traditional Transformers (such as T5, MarianMT) use an **Encoder-Decoder** architecture.

#### 1. Structure Formula Table (Pre-LN Paradigm)

| Step | Sub-module | Core Formula (Pre-LN) |
| :---------- | :--------------------------------------------------------------- | :------------------------------------------------------------------- |
| **1** | **Masked Self-Attention**`<br>`review history, keep logical consistency | $x_1 = x + \text{MaskedMHA}(\text{RMSNorm}(x))$ |
| **2** | **Cross-Attention** (optional)`<br>`query the source, get context | $x_2 = x_1 + \text{CrossAttn}(\text{RMSNorm}(x_1), \text{EncOut})$ |
| **3** | **FFN (SwiGLU)**`<br>`deep thinking, integrate information | $x_3 = x_2 + \text{SwiGLU}(\text{RMSNorm}(x_2))$ |

> **💡 The math advantage of Pre-LN**:
> The main path (Residual Path) is $x + f(x) + g(x) \dots$, so the derivative always contains the identity term $1$. This guarantees that gradient flow in deep networks **never vanishes** and is unlikely to **explode**.

#### 2. PyTorch Pseudocode

```python
class DecoderLayer(nn.Module):
    def forward(self, x, encoder_out=None):
        # 1. Masked Self-Attention (required)
        # is_causal=True automatically applies the lower-triangular mask
        residual = x
        x = self.norm1(x)
        x = residual + self.masked_mha(x, is_causal=True)
      
        # 2. Cross-Attention (only needed for Encoder-Decoder architectures)
        if encoder_out is not None:
            residual = x
            x = self.norm2(x)
            # Query comes from the Decoder, Key/Value come from the Encoder
            x = residual + self.cross_mha(x, context=encoder_out)
          
        # 3. FFN (SwiGLU)
        residual = x
        x = self.norm3(x)
        x = residual + self.ffn(x)
        return x
```

### 🧠 2. What Is Each Part of the Decoder Actually Computing?

#### 1. Masked Multi-Head Self-Attention (self-attention with blindfold)

* **Goal**: ensure the **causality** of generation. When generating the $t$-th word, it must never see word $t+1$.
* **Mathematical implementation**:

  $$
  \text{Attention}(Q,K,V) = \text{softmax}\left( \frac{QK^T}{\sqrt{d_k}} + \color{red}{\mathbf{M}_{\text{causal}}} \right) V
  $$

  where $\mathbf{M}_{\text{causal}}$ is a **lower-triangular matrix** (Upper Triangular Mask):

  $$
  \mathbf{M}_{\text{causal}} = \begin{bmatrix} 
  0 & -\infty & -\infty \\
  0 & 0 & -\infty \\
  0 & 0 & 0 
  \end{bmatrix}
  $$

  * **Principle**: $e^{-\infty} = 0$. After Softmax, the probability weights of the upper-right (future information) all become 0.

#### 2. Cross-Attention (the bridge to the Encoder)

* **Goal**: align the Decoder's `writing intent` with the Encoder's `source information`.
* **Collaboration mechanism (Q, K, V assignment)**:
  * **Query ($Q$)** $\leftarrow$ the output of the **Decoder's** previous layer. It represents: `I want to translate this word right now — where does it correspond to in the source?`
  * **Key ($K$)** $\leftarrow$ the **Encoder's** final output. It represents: `the index features of all words in the source.`
  * **Value ($V$)** $\leftarrow$ the **Encoder's** final output. It represents: `the content features of all words in the source.`
* **Dimension alignment**:
  * $Q \in (B, T_{tgt}, d)$
  * $K, V \in (B, T_{src}, d)$
  * Although the sequence lengths $T$ differ, the feature dimension $d$ must match; the attention mechanism handles the length difference automatically.

#### 3. FFN (SwiGLU variant)

* **Goal**: higher parameter efficiency, stronger nonlinear expressiveness.
* **Formula derivation**:
  $$
  \text{SwiGLU}(x) = (\text{Swish}(xW_g) \otimes (xW_{in})) W_{out}
  $$
* **Parameter count comparison**:
  * **Traditional FFN (BERT)**: intermediate layer $4d$. Parameters $\approx 2 \times 4d^2 = 8d^2$.
  * **SwiGLU (LLaMA)**: has 3 matrices; to keep total parameters similar, the intermediate layer is usually $\frac{8}{3}d$ (about $2.67d$).
    Parameters $\approx 3 \times 2.67d^2 \approx 8d^2$.
  * **Conclusion**: with the same parameter count, SwiGLU performs better.

### 🎯 3. Autoregressive Generation and Inference Optimization

#### 1. Inference acceleration: KV Cache

When generating the 100th word, the $K$ and $V$ of the first 99 words have already been computed — no need to recompute them.

* **Approach**: allocate space in GPU memory and store (Cache) the $K, V$ matrices computed at each layer.
* **Cost**: memory usage grows linearly with sequence length (a memory killer).

#### 2. Memory optimization: GQA (Grouped Query Attention)

To relieve the memory pressure from the KV Cache, LLaMA-2/3 uses GQA.

* **MHA (standard)**: 32 Q heads paired with 32 K, V heads. Memory usage 100%.
* **MQA (minimal)**: 32 Q heads sharing **1** K, V head. Memory usage 3%. (some quality loss)
* **GQA (compromise)**: 32 Q heads sharing **4** K, V heads. Memory usage 12.5%. (almost no quality loss)

### 🔄 4. Key Difference Summary: Encoder vs Decoder

| Feature | Encoder (BERT) | Decoder (GPT/LLaMA) |
| :------------------- | :----------------------------- | :--------------------------------------------- |
| **Core task** | **Understanding** | **Generation** |
| **Attention matrix** | **All-1s matrix** (bidirectional visibility) | **Lower-triangular matrix** (unidirectional visibility) |
| **Information flow** | Bidirectional | Auto-Regressive |
| **KV Cache** | Not needed | **Mandatory** (otherwise inference is extremely slow) |
| **Positional encoding** | Absolute positions are enough | Must have **extrapolation** (RoPE is standard) |
| **Collaboration** | Works independently | Parallel during training (Teacher Forcing)`<br>`Sequential during inference |
