# Transformer Encoder Explained

### Encoder Overview![encoder](./images/encoder_workflow.png)

This is the entire Encoder! It's like a **semantic refinement machine**: you feed in a sequence of words, and it outputs vectors that carry deep semantics.

---

### Part 1: The Full Structure of a Single Encoder Layer: Modern vs Classic

The Encoder/Block design of today's mainstream large models (LLaMA, PaLM, DeepSeek) has evolved significantly from the original 2017 paper.

#### 1. Structure Comparison Table

| Feature | 🏛️ Classic Architecture (BERT/RoBERTa) | 🚀 Modern Architecture (LLaMA/PaLM/GLM) |
| :------------------- | :------------------------------- | :---------------------------------------- |
| **Normalization position** | **Post-LN** (add first, then normalize) | **Pre-LN** (normalize first, then add) |
| **Normalization algorithm** | LayerNorm | **RMSNorm** (centering-free, more stable and faster) |
| **Activation function** | GELU / ReLU | **SwiGLU** (gated linear unit, stronger effect) |
| **Positional encoding** | Learnable / Sinusoidal | **RoPE** (rotary position encoding, strong extrapolation) |
| **Stability** | Deep stacks easily suffer gradient explosion, needs Warmup | Extremely stable, can easily train 100+ layers |

#### 2. Code Implementation (Pre-LN Paradigm)

```python
class EncoderLayer(nn.Module):
    def forward(self, x):
        # 1. Self-Attention branch (Pre-LN)
        # The norm here is usually RMSNorm
        residual = x
        x = self.norm1(x)
        x = residual + self.attn(x)  # residual connection
      
        # 2. FFN branch (Pre-LN)
        residual = x
        x = self.norm2(x)
        x = residual + self.ffn(x)   # residual connection
      
        return x
```

### Part 2: What Is Each Part of the Encoder Actually Computing?

#### 1. Input Stage

$$
\text{Input} = \text{WordEmbedding} + \text{PositionalEncoding}
$$

* **Word Embedding**: look up the table to get a word vector (e.g., 512-dimensional).
* **Positional Encoding**:
  * **Absolute position** (BERT): a learned Position Embedding.
  * **Relative position** (RoPE): the current SOTA standard. It injects positional information by **rotating the angle of the vector**, letting the model understand `distance`.

#### 2. The Core: Multi-Head Self-Attention

This is the soul of the Encoder. A Token can `see` the entire sentence thanks to it.

$$
\text{Attention}(Q,K,V) = \text{softmax}\left( \frac{Q K^T}{\sqrt{d_k}} + \color{red}{\text{M}_{\text{pad}}} \right) V
$$

* $\sqrt{d_k}$: **scaling factor**. It prevents the dot product from becoming too large and causing Softmax gradients to vanish.
* $\color{red}{\text{M}_{\text{pad}}}$ (**Padding Mask**):
  * **Key point**: the Encoder is **bidirectional** — it can see the whole text.
  * **Role**: it only exists to mask out `<pad>` placeholders (usually set to $-\infty$), preventing the model from wasting attention on meaningless padding.
* **FlashAttention**: a must-have in modern engineering. Through GPU memory I/O optimization, it achieves **3-5x speedup** without changing the mathematical results.

#### 3. Deep Transformation: Feed-Forward Network (FFN / MLP)

Attention is responsible for `aggregating information`, while the FFN is responsible for `digesting information` (nonlinear transformation).

**Classic form (BERT)**:

$$
\text{FFN}(x) = \text{GELU}(x W_1 + b_1) W_2 + b_2
$$

*(Dimension change: $d \to 4d \to d$)*

**Modern form (SwiGLU)**:

$$
\text{SwiGLU}(x) = (\text{Swish}(x W_g) \otimes (x W_{in})) W_{out}
$$

*(Dimension change: $d \to \frac{8}{3}d \to d$)*

> **Note**: to keep the parameter count consistent with the classic FFN, the intermediate dimension is usually scaled down to $\frac{2}{3}$ of the original.

### Part 3: What Does the Encoder Finally Output?

After stacking $N$ layers, the output matrix has the shape:

$$
\boxed{(\text{Batch}, \text{Seq\_Len}, \text{Hidden\_Dim})}
$$

Each row vector is the **deep contextual representation (Contextual Representation)** of the current Token after fusing **information from the entire sequence**.

#### An Example 🌰

Input: `[我, 爱, 吃, 苹, 果]` (I, love, eat, ap, ple)
In the output of layer 12, the vector at the position of **`我`** (I) no longer only represents the character `我`; it also implicitly encodes:

1. The object of the action is `苹果` (apple).
2. The sentiment is `爱` (love).
3. The grammatical role is `主语` (subject).

**How to use this output?**

* **Classification tasks**: take the vector at the `[CLS]` token, or average all vectors (Mean Pooling).
* **Sequence labeling**: attach a classification head to each Token's vector (e.g., NER entity recognition).

### Part 5: One-Sentence Summary

**The essential workflow of the Encoder:**

1. **Global consultation (Self-Attention)**: take your own question and ask everyone in the sentence, aggregating information.
2. **Deep reflection (FFN)**: combine the gathered information with your own understanding and process it nonlinearly.
3. **Final goal**: turn the **`vague literal input`** into **`precise semantic understanding`**.
