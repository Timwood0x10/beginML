# Residual Connections and Layer Normalization (Add & Norm)

## 🧩 1. What Is a Residual Connection?

**One-sentence explanation**:
The core of the residual connection is to **explicitly let the network learn the "Residual Function"**, i.e., to learn the "amount of change" rather than the "full value".

### 1.1 Mathematical Definition

$$
\boxed{H(x) = x + F(x)}
$$

Where:

- $x$: **Identity Mapping** — the data flows through the Shortcut without loss.
- $F(x)$: **Residual Mapping** — the "repair part" the network actually needs to learn.
- $H(x)$: the ideal mapping of the final output.

### 1.2 Core Intuition

> 💡 **Analogy**:
> A traditional network is like "rewriting" an article.
> A residual network is like "proofreading" an article: $x$ is the original text, and $F(x)$ is the teacher's red-pen corrections.
> If there's nothing to fix, $F(x) \to 0$, and the output is just the original text $x$. This guarantees that **adding more layers never makes the result worse** (identity mapping).

## ⚙️ 2. The Math Behind LayerNorm

LayerNorm usually follows right after the Residual. Why does the Transformer use LN instead of BN?

### 2.1 Computation Formula

For an input vector $x \in \mathbb{R}^d$, LayerNorm normalizes along the **feature dimension**:

1. **Mean**: $\mu = \frac{1}{d} \sum_{i=1}^d x_i$
2. **Variance**: $\sigma^2 = \frac{1}{d} \sum_{i=1}^d (x_i - \mu)^2$
3. **Normalize + affine transform**:
   $$
   \boxed{\text{LN}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \cdot \gamma + \beta}
   $$

   * $\gamma, \beta$ are learnable parameters (Gain & Bias) that let the model restore its original expressive power.

### 2.2 Modern Variant: RMSNorm (the LLaMA Standard)

Modern large models (e.g., LLaMA, PaLM) commonly use **RMSNorm**. It drops the mean $\mu$ and only rescales the magnitude:

$$
\text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d} \sum x_i^2 + \epsilon}} \cdot \gamma
$$

* **Advantage**: less computation, comparable performance.

## 🏗️ 3. Position Architecture in the Transformer

Each Transformer Block contains two core sublayers, and each sublayer is followed by an **Add & Norm**.

### 1. Encoder Block (2 residual structures)

$$
\begin{aligned}
x_1 &= \text{Norm}(x + \text{SelfAttention}(x)) \\
x_2 &= \text{Norm}(x_1 + \text{FFN}(x_1))
\end{aligned}
$$

### 2. Decoder Block (3 residual structures) ⚠️

The Decoder has one extra Cross-Attention layer:

$$
\begin{aligned}
x_1 &= \text{Norm}(x + \text{MaskedSelfAttention}(x)) \\
x_2 &= \text{Norm}(x_1 + \text{CrossAttention}(x_1, \text{EncoderOut})) \\
x_3 &= \text{Norm}(x_2 + \text{FFN}(x_2))
\end{aligned}
$$

## ⚖️ 4. Key Choice: Post-LN vs Pre-LN

Whether LayerNorm goes "before the addition" or "after the addition" determines the fate of deep networks.

### 1. Post-LN (original Transformer, BERT)

$$
x_{t+1} = \text{Norm}(x_t + F(x_t))
$$

* **Structure**: add the residual first, then normalize.
* **Advantage**: if training succeeds, final performance may be slightly better (the normalized output goes directly into the next layer, high utilization).
* **Drawback**: **gradients easily explode during backpropagation**. In deep networks, you must pair it with tiny learning rates and complex Warmup to converge.

### 2. Pre-LN (GPT-2, LLaMA, the modern mainstream)

$$
x_{t+1} = x_t + F(\text{Norm}(x_t))
$$

* **Structure**: normalize the input first, then go into the sublayer, then add the residual.
* **Advantage**: **extremely stable training**. The main path (Highway) is always a clean $x + \dots + x$, so gradient flow is exceptionally smooth.
* **Drawback**: in very deep stacks it may suffer "representation collapse" (but that's not a bottleneck for today's LLMs).

> **🏆 Conclusion**: modern large models (LLMs) almost all use the **Pre-LN** architecture.

## 📈 5. Why Does It Work? (Mathematical Derivation)

### 1. Solving Gradient Vanishing

Consider a simplified network $x_{L} = x_0 + \sum_{i=1}^L F_i(x_{i-1})$.
The gradient of the loss $\mathcal{L}$ with respect to the input $x_0$ is:

$$
\frac{\partial \mathcal{L}}{\partial x_0} = \frac{\partial \mathcal{L}}{\partial x_L} \cdot \left( \boxed{1} + \frac{\partial}{\partial x_0} \sum_{i=1}^L F_i \right)
$$

* **Without residuals**: the gradient is a product $\prod \frac{\partial F}{\partial x}$. If each layer's derivative is less than 1, multiplying it dozens of times turns it into 0 (gradient vanishing).
* **With residuals**: the gradient contains a constant **$1$**.
  * This is like a **"Gradient Highway"**.
  * No matter how deep the network, the gradient signal can always travel back to the bottom layers losslessly through this $1$.

### 2. The Ensemble Hypothesis

A residual network can be viewed as an **exponential ensemble** of many shallow networks of different depths.

* Data can choose to take the Shortcut (skip the current layer), or take $F(x)$ (pass through the current layer).
* An $L$-layer ResNet actually contains $2^L$ possible path combinations.

## 🔍 6. LN vs BN (Why Not BatchNorm?)

| Feature | LayerNorm (LN) | BatchNorm (BN) |
| :------------------- | :--------------------------------------------- | :---------------------------------------------------- |
| **Normalization axis** | **Horizontal slice**: normalize all features of a single sample | **Vertical slice**: normalize the same feature across all samples in a Batch |
| **Batch dependence** | **None** (works even with Batch=1) | **Strong** (statistics are unreliable with tiny Batch) |
| **Suitable data** | **Variable-length sequences (RNN/Transformer)** | Fixed-size images (CNN) |
| **Inference** | Same computation logic as training | Must use the Running Mean/Var collected during training |

> **Core reason**:
> NLP sentences have varying lengths (lots of Padding).
> With BN, the 0s from Padding would seriously corrupt the mean and variance statistics.
> LN, by contrast, normalizes "each word vector by itself", completely unaffected by sentence length or Batch Size.

## 💻 7. PyTorch Implementation (Pre-LN Code)

```python
import torch
import torch.nn as nn

class ResidualBlock(nn.Module):
    def __init__(self, d_model):
        super().__init__()
        self.norm = nn.LayerNorm(d_model)     # 1. normalization layer
        self.attn = nn.MultiheadAttention(d_model, num_heads=8)
        self.dropout = nn.Dropout(0.1)

    def forward(self, x):
        # x shape: [seq_len, batch, d_model]
      
        # === Pre-LN structure ===
      
        # 1. save the residual first (Identity)
        residual = x 
      
        # 2. normalize (Norm)
        x_norm = self.norm(x)
      
        # 3. sublayer computation (Attention)
        attn_out, _ = self.attn(x_norm, x_norm, x_norm)
      
        # 4. residual connection (Add)
        output = residual + self.dropout(attn_out)
      
        return output
```
