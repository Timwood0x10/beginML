# How to Build an Agent (In Progress)

> **Status**: section placeholder. This directory will systematically cover
> building an Agent from scratch; the outline below is planned, content is
> being filled in gradually.

## Planned Outline

1. **Agent Fundamentals**: the LLM is the brain, the Agent is the body —
   what an Agent is and how it differs from a chatbot.
2. **Function Calling**: how to let a model call external tools, structured
   output, and tool protocols.
3. **Memory Systems**: tiered design of short-term (context window),
   mid-term (vector retrieval / RAG) and long-term (database) memory.
4. **Planning & Reasoning**: ReAct, Plan-and-Execute, Reflection, task
   decomposition.
5. **Multi-Agent Collaboration**: Orchestrator-Worker, black-box review,
   role-based division of labor.
6. **Engineering Practice**: agent framework selection, streaming responses,
   permission & safety boundaries, observability.
