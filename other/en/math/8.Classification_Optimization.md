# The Optimization Logic of Classification Models

## Overview: How do we make the model output $G(X)$ `align with` the true label $T(X)$?

In a binary classification problem, we have:

- **True label $T(X)$**: usually $\{1, -1\}$.
- **Model output $G(X)$**: a continuous value that we need to give meaning to.
- **Learning goal**: adjust the model parameters $\theta$ so that on the training set $\tilde{X}$, the model output $G(X)$ matches the true label $T(X)$ as closely as possible — and this consistency generalizes to all data (the full set X).

How do we measure this `consistency`? The figure below shows three different approaches.

---

## Approach 1: Least Squares

### 1. The metric we assign

We treat the model output $f_\theta^{[G]}(\tilde{X})$ as a continuous value and hope it can directly fit the true label $f_\theta^{[T]}(\tilde{X})$ (here T stands for Target, i.e., the true label).

### 2. Loss function (measuring `inconsistency`)

**Formula:**

$$
(f_\theta^{[G]}(\tilde{X}) - f_\theta^{[T]}(\tilde{X}))^2 \rightarrow \sigma^2
$$

- $f_\theta^{[G]}(\tilde{X})$: the model's output for a training sample $\tilde{X}$.
- $f_\theta^{[T]}(\tilde{X})$: the true label, e.g., 1 or -1.
- $\rightarrow \sigma^2$: we want the expected value (or average) of this squared error to be as small as possible.

**Intuitive explanation:**
It's like a `dart game`. The true label is the bullseye, and the model output is where the dart lands. We compute the square of the distance from each dart to the bullseye, then add up all these `squared distances`. The goal is to minimize the total squared distance.

Why squared? Because it harshly punishes darts that land very far from the bullseye (outliers).

### 3. Drawbacks

- Logically awkward: treating category labels like $\{1,-1\}$ as continuous values to be fitted is conceptually strange.
- Sensitive to outliers: a single outlier can produce a huge squared error and pull the whole model "off course".
- Punishes "too-good" predictions: if the label is 1 and the model very confidently predicts 10, MSE actually penalizes it heavily, $(10-1)^2 = 81$ — which is quite unreasonable.

---

## Approach 2: Maximum Likelihood Estimation

### 1. The metric we assign

Instead of treating the model output as a number, we convert it into a probability.

**Formula:**

$$
\text{sigmoid}(f_\theta^{[G]}(\tilde{X})) \rightarrow P(Y|X,\theta), Y \in \{0,1\}
$$

- $\text{sigmoid}(\cdot)$: a function that squeezes any value into the $(0, 1)$ interval, which can naturally be interpreted as a probability.
- $P(Y|X,\theta)$: the probability that the label is $Y$, given the data $X$ and the model parameters $\theta$.

**Intuitive explanation:**
The model no longer says `this is an apple` outright; instead it says `I am 70% sure this is an apple`. This is more flexible and captures the model's own `uncertainty`.

### 2. Loss function (measuring `inconsistency`)

**Formula:**

Formula:

$$
\text{Maximize Likelihood} \Longleftrightarrow \text{Minimize Cross Entropy}
$$

$$
\max_{\theta} \prod_{i} P(y_i | x_i, \theta) \quad \Longleftrightarrow \quad \min_{\theta} \underbrace{ - \sum_{i} \log P(y_i | x_i, \theta) }_{\text{Cross Entropy}}
$$

Intuition: we play `Sherlock Holmes`. The training data is a trail of footprints (clues). The model parameters $\theta$ are the different suspects.

Goal: find the suspect `most likely to have left this trail of footprints`.

Mathematically, this is equivalent to pushing the model's predicted probability for the correct class as close to 1 as possible.

Advantages

- **Most mainstream**: this is the standard approach for logistic regression and modern deep learning classifiers.
- **Fault tolerance**: as long as the probability > 0.5
- **Probabilistic output**: the result is more interpretable — we can know the model's confidence.
- **Great for classification**: it is currently the most mainstream loss function for neural network classification tasks.
  Even if the classification is correct, during training it keeps pushing the probability toward 1.0.

## Approach 3: SVM (Support Vector Machine)

### 1. The metric we assign

We view the model output as the distance from a point to the hyperplane.

**Formula:**

$$
\text{Geometric Distance} = \frac{1}{||w||_2} f_\theta^{[G]}(\tilde{X}) = \frac{w^T x +b}{||w||_2}
$$

- $f_\theta^{[G]}(\tilde{X})$: usually $w^\top x + b$, which can be understood as the "functional distance".
- $\frac{1}{\|w\|_2}$: a normalization factor that converts it into a true "geometric distance".
- Positive means on one side of the boundary, negative on the other. The larger the absolute value, the farther from the boundary (the safer).

**Intuitive explanation:**
The value output by the model represents how far a data point is from the boundary line we drew (the decision boundary). Positive means on one side, negative on the other; the larger the absolute value, the farther away.

### 2. Loss function (measuring `inconsistency`)

SVM's goal is quite unique — it is a constrained optimization problem:

Optimization objective:

**Formula:**

$$
\begin{cases}
\min \frac{1}{2} {\|w\|}^2  (1. Make the road as wide as possible) \\
s.t. y_i(w^T x_i + b) \ge 1 (2. All samples must lie on both sides of the road)
\end{cases}
$$

Intuition: `paving a road`.

- First, we must completely separate the two classes.
- Second, not only separate them, but also pave the widest double-yellow line in the middle (maximizing the margin $\Longleftrightarrow$ minimizing $\|w\| ^2$).
- The people pressed right against the edge of the road are the **"support vectors"**.

In actual optimization, this translates into the Hinge Loss:

$$
L(y,f(x)) = max(0,1-y \cdot f(x))
$$

**Intuitive explanation:**
SVM's goal is very unique:

- **Only cares about key players**: SVM only cares about the "support vectors" closest to the boundary.
- **Robustness**: for ordinary samples that are far away (easy to classify), SVM simply ignores them (Loss=0). This is completely different from the previous two methods (where every point participates in the computation).
- **Generalization guarantee**: a large margin directly corresponds to low VC dimension, i.e., better generalization.

### 3. Advantages

- **Strong generalization**: maximizing the margin has been proven to effectively lower the model's VC dimension, yielding better generalization performance.
- **Only cares about support vectors**: it is insensitive to points far from the boundary, making the model more robust.

---

## Summary: the essential difference between the three approaches

| Aspect | Least Squares | Maximum Likelihood Estimation | SVM |
| :----- | :------------ | :--------------------------- | :-- |
| **Meaning of the metric** | Numerical fitting | Probabilistic interpretation | Geometric distance |
| **Core idea** | Minimize squared error | Maximize data likelihood | Maximize classification margin |
| **Focus** | All data points | All data points | Only support vectors near the boundary |
| **Loss function** | Mean squared error (MSE) | Cross-Entropy | Hinge Loss |
| **Life analogy** | Throwing darts, trying to hit the bullseye every time | Solving a case, finding the suspect that best explains the clues | Painting a double-yellow line, trying to make the road as wide as possible |
| **For "too-good" samples** | Punishes (this is silly) | Rewards (probability approaches 1) | Ignores (Loss=0, this is cool) |
