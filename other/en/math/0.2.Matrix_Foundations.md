# [0.2] Matrix Theory: Geometry & Transformation of Data

**Abstract**: Matrix theory is the **native language** of machine learning. From microscopic **data representation** (feature and parameter matrices) to macroscopic **model computation** (forward pass is matrix multiplication), from the gradient flow of **optimization** to the compression essence of **dimensionality reduction** (PCA/SVD), matrix operations are everywhere. Yet in deep learning, a matrix isn't just a static table of numbers — it's a **dynamic spatial transformation operator**. It can both **lift** low-dimensional data into higher dimensions to achieve linear separability per **Cover's theorem** (Embedding/kernel tricks), and **compress** high-dimensional data to extract the essence (LoRA). This chapter skips the tedious hand-computation of determinants and goes straight into the deep connection between matrix rank and model capacity, the decisive role of the eigenvalue spectrum in training stability, and the math behind SVD in efficient fine-tuning of large models.

---

## 1. Vectors and Tensors: Containers of Data

In PyTorch/TensorFlow, we don't just handle matrices — we handle **Tensors**.

### 1.1 The Physical Meaning of Dimensions

* **Scalar (0-D)**: Loss values, learning rates.
* **Vector (1-D)**: feature vector $\mathbf{x} \in \mathbb{R}^d$, bias $\mathbf{b}$.
* **Matrix (2-D)**: weight $\mathbf{W} \in \mathbb{R}^{out \times in}$, grayscale images.
* **Tensor (N-D)**:
  * $(B, C, H, W)$: a batch of image data (Batch Size, Channel, Height, Width).
  * $(B, T, D)$: Transformer input (Batch, Sequence Length, Embedding Dim).

### 1.2 Broadcasting

This is an important engineering extension of matrix algebra. When two tensors of different shapes operate together, the system automatically "copies" the lower-dimensional tensor to match the higher-dimensional one.

* **Mathematical essence**: $\mathbf{Y} = \mathbf{W}\mathbf{X} + \mathbf{b}$.
* Here $\mathbf{W}\mathbf{X}$ has shape $(B, D_{out})$, while $\mathbf{b}$ is $(D_{out})$.
* Broadcasting implicitly expands $\mathbf{b}$ to $(1, D_{out})$ and then copies it $B$ times along the batch dimension. This dramatically improves memory efficiency.

## 2. Linear Transformations and Neural Networks

The mathematical essence of a fully connected layer (Linear Layer) is an affine transformation:
$$ \mathbf{y} = f(\mathbf{W}\mathbf{x} + \mathbf{b}) $$

### 2.1 The Geometric View of Matrix Multiplication

The matrix $\mathbf{W}$ maps the input space $\mathbb{R}^{in}$ to the output space $\mathbb{R}^{out}$.

* **Diagonal matrices**: scale along the coordinate axes.
* **Orthogonal matrices**: rotate or reflect (don't change vector length, norm-preserving).
* **Nonlinear activations**: $f(\cdot)$ (e.g., ReLU) **folds** the space. Without nonlinearity, no matter how many layers you stack, the result is equivalent to a single linear transformation $\mathbf{W}_{total} = \mathbf{W}_n \dots \mathbf{W}_1$.

### 2.2 Matrix Rank and Model Capacity

**Rank** measures the dimension of the space spanned by a matrix's row/column vectors — i.e., the **dimension of effective information**.

* **Rank Collapse**: in deep neural networks, if the rank of weight matrices gradually decreases, deep feature representations degenerate into a low-dimensional subspace, and the model can no longer distinguish complex classes.
* **Dead Neurons**: can be understood as some rows of $\mathbf{W}$ becoming zero vectors, lowering the effective rank.

---

## 3. Lifting & Mapping: Cover's Theorem

Matrices can not only reduce dimensions (compress); by adding columns, they can also **lift** into higher dimensions. This is key to handling complex nonlinear data.

### 3.1 Cover's Theorem

**"Project a complex nonlinear classification problem into a high-dimensional space, and it becomes more likely to be linearly separable."**

Consider the classic **XOR problem**: on the 2D plane, $(0,0), (1,1)$ are the negative class and $(0,1), (1,0)$ are the positive class. No matter how you draw a straight line, you can't separate them.
But if we define a lifting map $\phi: \mathbb{R}^2 \to \mathbb{R}^3$:
$$ \phi([x_1, x_2]) = [x_1, x_2, x_1 x_2] $$
In this 3D space, the four points become $(0,0,0), (1,1,1)$ and $(0,1,0), (1,0,0)$. Now a 2D plane can separate them perfectly.

### 3.2 "Lifting" in Deep Learning

* **Embedding layers**:
    In natural language processing, a word ID is just a scalar (1-D). The Embedding matrix $\mathbf{E} \in \mathbb{R}^{V \times D}$ is essentially a lookup table that maps scalars into a $D$-dimensional (e.g., 512-D) space. In this high-dimensional manifold, the vector distance between "king" and "queen" gains semantic geometric meaning.
* **Transformer FFN layers**:
    In the Transformer's feed-forward network, the dimension is typically first lifted from $d_{model}$ to $4d_{model}$, passed through a nonlinear activation, and then reduced back. This "lift-activate-reduce" operation exists precisely to disentangle the data in a higher-dimensional space.

## 4. Eigendecomposition and Training Dynamics

For a square matrix $\mathbf{A} \in \mathbb{R}^{n \times n}$, if $\mathbf{A}\mathbf{v} = \lambda \mathbf{v}$, then $\lambda$ is an eigenvalue.

### 4.1 The Eigenspectrum

The set of all eigenvalues of a matrix is called its **spectrum**. The spectral radius $\rho(\mathbf{A}) = \max_i |\lambda_i|$ determines the long-term behavior of matrix multiplication.
In RNNs or deep networks, gradient backpropagation involves chain products of weights $\mathbf{W}^L$:

* **Gradient explosion**: if $\rho(\mathbf{W}) > 1$, gradients grow exponentially with depth.
* **Gradient vanishing**: if $\rho(\mathbf{W}) < 1$, gradients decay exponentially with depth.

### 4.2 Spectral Normalization

To stabilize GAN training (satisfying Lipschitz continuity), we need to bound the spectral radius of the discriminator's weights.
$$ \mathbf{W}_{SN} = \frac{\mathbf{W}}{\sigma(\mathbf{W})} $$
where $\sigma(\mathbf{W})$ is the largest singular value of $\mathbf{W}$ (approximately the spectral radius).

## 5. Singular Value Decomposition (SVD) and Low-Rank Adaptation

Since weight matrices are usually not square, eigendecomposition doesn't apply. **SVD** is the Swiss Army knife of matrix analysis.
Any matrix $\mathbf{W} \in \mathbb{R}^{m \times n}$ can be decomposed as:
$$ \mathbf{W} = \mathbf{U} \mathbf{\Sigma} \mathbf{V}^T $$
where the diagonal elements of $\mathbf{\Sigma}$, $\sigma_i$, are the singular values, and $\sigma_1 \ge \sigma_2 \ge \dots \ge 0$.

### 5.1 Geometric Meaning

SVD deconstructs any linear transformation into three steps:

1. **Rotation** ($\mathbf{V}^T$): coordinate system change.
2. **Scaling** ($\mathbf{\Sigma}$): stretch/compress along the new coordinate axes.
3. **Rotation** ($\mathbf{U}$): map into the output space.

### 5.2 The Math Behind LoRA (Low-Rank Adaptation)

In large-model fine-tuning, we find that the weight update $\Delta \mathbf{W}$ has an extremely low **Intrinsic Dimension**.
Although $\mathbf{W} \in \mathbb{R}^{d \times d}$ is full-rank, we assume $\Delta \mathbf{W}$ can be approximated by a low-rank matrix:
$$ \Delta \mathbf{W} \approx \mathbf{B} \mathbf{A} $$
where $\mathbf{B} \in \mathbb{R}^{d \times r}, \mathbf{A} \in \mathbb{R}^{r \times d}$, and $r \ll d$.
This is essentially a truncated form of SVD (Truncated SVD), keeping only the top $r$ principal change directions.

### 5.3 The Statistical Duality of PCA and SVD

Principal Component Analysis (PCA) aims to find the directions of maximum data variance. Mathematically this is equivalent to the eigendecomposition of the covariance matrix, but in engineering it's usually implemented via SVD.

Let the centered data matrix be $\mathbf{X} \in \mathbb{R}^{n \times d}$ ($n$ samples, $d$ features).

1. **Statistical view (PCA)**:
    Compute the covariance matrix $\mathbf{C} = \frac{1}{n-1} \mathbf{X}^T \mathbf{X}$.
    Eigendecompose $\mathbf{C}$: $\mathbf{C} = \mathbf{V} \mathbf{\Lambda} \mathbf{V}^T$.
    $\mathbf{V}$ gives the principal component directions.

2. **Algebraic view (SVD)**:
    Directly SVD $\mathbf{X}$: $\mathbf{X} = \mathbf{U} \mathbf{\Sigma} \mathbf{V}^T$.
    Substituting into $\mathbf{X}^T \mathbf{X}$:
    $$ \mathbf{X}^T \mathbf{X} = (\mathbf{U} \mathbf{\Sigma} \mathbf{V}^T)^T (\mathbf{U} \mathbf{\Sigma} \mathbf{V}^T) = \mathbf{V} \mathbf{\Sigma}^T \underbrace{\mathbf{U}^T \mathbf{U}}_{\mathbf{I}} \mathbf{\Sigma} \mathbf{V}^T = \mathbf{V} \mathbf{\Sigma}^2 \mathbf{V}^T $$

**Conclusion**:

* The covariance matrix's **eigenvectors** = the data matrix's **right singular vectors** ($\mathbf{V}$).
* The relation between the covariance matrix's **eigenvalues** $\lambda_i$ and the singular values $\sigma_i$: $\lambda_i = \frac{\sigma_i^2}{n-1}$.
* **Engineering significance**: doing SVD directly on $\mathbf{X}$ is numerically more stable and avoids explicitly computing $\mathbf{X}^T \mathbf{X}$ (preventing precision loss).

## 6. Positive Definite Matrices and the Hessian

In optimization, the second-order derivatives form the **Hessian matrix** $\mathbf{H}$.

### 6.1 Positive Definiteness

If for any $\mathbf{x} \ne 0$, we have $\mathbf{x}^T \mathbf{H} \mathbf{x} > 0$, then $\mathbf{H}$ is called positive definite.

* **Geometric meaning**: $\mathbf{H}$ being positive definite means the Loss surface is **bowl-shaped**, with a unique global minimum.
* **Indefinite**: if the eigenvalues are mixed positive and negative, the point is a **Saddle Point**. In high-dimensional non-convex optimization, saddle points are far more common than local minima and are the main cause of training stalls.

## 7. Engineering Practice: Lifting to Solve XOR and SVD Compression

The code below has two parts:

1. Demonstrates how **Feature Mapping (Lifting)** turns inseparable XOR data into linearly separable data.
2. Demonstrates how **SVD** compresses large matrices (the LoRA principle).

```python
import torch
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

def demo_lifting_xor():
    """
    Demonstrate the power of matrix lifting: solving the XOR problem
    """
    # 1. define the 2D XOR data (inseparable)
    # Class 0: (0,0), (1,1)
    # Class 1: (0,1), (1,0)
    X = torch.tensor([[0,0], [1,1], [0,1], [1,0]], dtype=torch.float32)
    y = torch.tensor([0, 0, 1, 1])
    
    # 2. define the lifting map phi: (x1, x2) -> (x1, x2, |x1-x2|)
    # this is a nonlinear feature transformation
    def phi(x):
        x1 = x[:, 0]
        x2 = x[:, 1]
        # build the third dimension as an interaction term of x1 and x2, e.g., |x1 - x2| or (x1-x2)^2
        x3 = (x1 - x2) ** 2 
        return torch.stack([x1, x2, x3], dim=1)

    X_high = phi(X)
    
    print("--- Lifting demo ---")
    print(f"Original 2D data:\n{X}")
    print(f"Lifted 3D data:\n{X_high}")
    
    # 3. visualization
    fig = plt.figure(figsize=(10, 4))
    
    # 2D view
    ax1 = fig.add_subplot(121)
    ax1.scatter(X[y==0,0], X[y==0,1], color='red', label='Class 0')
    ax1.scatter(X[y==1,0], X[y==1,1], color='blue', label='Class 1')
    ax1.set_title("2D: Linearly Inseparable")
    ax1.grid(True)
    
    # 3D view
    ax2 = fig.add_subplot(122, projection='3d')
    ax2.scatter(X_high[y==0,0], X_high[y==0,1], X_high[y==0,2], c='red', s=60)
    ax2.scatter(X_high[y==1,0], X_high[y==1,1], X_high[y==1,2], c='blue', s=60)
    ax2.set_title("3D: Linearly Separable (by a plane)")
    ax2.set_xlabel('x1'); ax2.set_ylabel('x2'); ax2.set_zlabel('(x1-x2)^2')
    
    plt.tight_layout()
    plt.show()

def demo_svd_compression():
    """
    Demonstrate SVD compression and LoRA parameter counting
    """
    print("\n--- SVD compression demo ---")
    d_in, d_out = 100, 100
    W = torch.randn(d_out, d_in) # random full-rank matrix
    
    # SVD decomposition
    U, S, V = torch.svd(W)
    
    # keep the top 5 principal components (Rank=5)
    r = 5
    W_approx = U[:, :r] @ torch.diag(S[:r]) @ V[:, :r].t()
    
    # count parameters
    params_full = d_in * d_out
    params_lora = (d_in * r) + (d_out * r)
    
    print(f"Original matrix size: {d_out}x{d_in} (params: {params_full})")
    print(f"Low-rank matrix (Rank={r}) params: {params_lora}")
    print(f"Compression ratio: {params_lora/params_full*100:.1f}%")
    print(f"Approximation error (MSE): {torch.mean((W - W_approx)**2):.6f}")


def demo_hessian_spectrum():
    """
    Demonstrate Hessian eigenvalues and critical point types (saddle vs extremum)
    """
    import torch.autograd.functional as F_grad
    
    print("\n--- Hessian spectrum analysis demo ---")
    
    # define two functions
    # f1: bowl-shaped function (all positive curvature) -> x^2 + y^2
    def f_min(x):
        return x[0]**2 + x[1]**2
    
    # f2: saddle function (curves up in one direction, down in the other) -> x^2 - y^2
    def f_saddle(x):
        return x[0]**2 - x[1]**2
    
    # test point (0,0)
    input_point = torch.tensor([0.0, 0.0])
    
    # 1. analyze f_min
    H_min = F_grad.hessian(f_min, input_point)
    # torch.linalg.eigvals returns complex numbers; we only look at the real part
    evals_min = torch.linalg.eigvals(H_min).real 
    print(f"Function f = x^2 + y^2 at (0,0):")
    print(f"  Hessian:\n{H_min}")
    print(f"  Eigenvalues: {evals_min} -> all positive (All Positive)")
    print(f"  Conclusion: this is a local minimum (Local Minima)\n")
    
    # 2. analyze f_saddle
    H_saddle = F_grad.hessian(f_saddle, input_point)
    evals_saddle = torch.linalg.eigvals(H_saddle).real
    print(f"Function f = x^2 - y^2 at (0,0):")
    print(f"  Hessian:\n{H_saddle}")
    print(f"  Eigenvalues: {evals_saddle} -> one positive, one negative (Mixed)")
    print(f"  Conclusion: this is a saddle point (Saddle Point)! Optimizers easily get stuck here.")



if __name__ == "__main__":
    demo_lifting_xor()
    demo_svd_compression()
    demo_hessian_spectrum()

```

Summary

Matrix theory unifies geometry and computation in machine learning:

* Lifting: through feature mapping (Cover's theorem/Embedding), turn low-dimensional inseparability into high-dimensional separability.

* Projection: through SVD/PCA, extract core information and remove noise.

* Eigenvalues: control the stability of gradient flow and prevent explosions.

![xor_lifting_demo](../images/xor_lifting_demo.gif)

* Phase 1 (2D view): shows XOR data "entangled" on the 2D plane, impossible to separate with a straight line.

* Phase 2 (lifting process): uses $z = (x_1 - x_2)^2$ to lift the data points "off the ground". You'll see points of different classes move to different heights.

* Phase 3 (3D rotation and slicing): rotate the view and insert a hyperplane in the middle, showing linear separability in high-dimensional space.
